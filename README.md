mend: one command-line tool that applies the edits AI models write, in four formats, to a tree of text files — unified diffs, SEARCH/REPLACE blocks, V4A patches, and JSON tool calls. It matches lines at three tiers of whitespace tolerance, keeps CRLF and final line breaks as the spec requires, and writes every file or nothing at all.

## Run it

```sh
node main.ts
```
